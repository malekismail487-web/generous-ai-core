# Generated scientific model / prospective evidence bridge

Status: experimental component, implemented and locally exercised. Cognitive
advantage, original discovery, physical experimentation and production authority
are not established. Live comparison remains pending. Default Ultra is unchanged.

## Actual gap and new capability

The previous science path requires host-supplied `mechanismCatalog` identities,
descriptions and enumerated experiments. NYX can reason about those mechanisms,
commit forecasts and revise after Omega observations, but cannot contribute an
executable mathematical model outside that prewritten catalog. More entities or
more descriptions would not repair that gap.

`runNyxScientificModelGeneration` now uses the existing NYX completion boundary
to propose competing arithmetic models from admitted measurements, input names,
explicit rational parameters, assumptions and uncertainty. Nemotron remains the
shared cognitive substrate: this is not an independently developed reasoning
engine or an additional model controller. Every candidate is data, not a command.

`ScientificModelSession` reuses the exact native workbench and original algebraic
frontend to derive predictions at immutable calibration and prospective inputs.
A separate original-source Python parser/Fraction interpreter checks every point
derivation. A proposed model is rejected if it contradicts admitted exact
measurements; unsupported computation/verifier failures remain insufficient
evidence. Admission means **checked predictions**, not scientific truth.

Only host-owned references can enter the bridge. Generated model identities and
forecasts are registered before constructing the existing immutable research
objective; the original closed-catalog checks are not loosened. The existing
`ResearchEvidenceGraph` commits E1 hypotheses before observations, selects a
discriminating experiment, retains contradictions and concludes only within the
modeled family with independent acceptance false. Correlated models retain one
cognition provenance root, not one independent vote per generated entity.

The existing Omega R3B experiment runner gains an explicit host-owned rational
readout for approved measurement tools. It interprets only a bounded JSON scalar
from the same hash-pinned, separately authorized isolated execution. The
measurement must echo the exact planned point identity and input bindings;
a matching numeric value measured at the wrong input is rejected. Unknown
measurements produce an **outside-all-current-predictions** outcome rather than
manufactured support. Additional fields, malformed output, unauthorized/replayed
execution and unexpected mutations remain rejected. Models cannot supply a
script, command, readout policy or capability token through this interface.

## Scope, resources and ownership

The first domain is deterministic rational scalar response models over 1..3
declared inputs: up to 16 model parameters, 12 admitted measurements and 16
prospective points, using only ADD/SUB/MUL/DIV. Native source-constant, expression,
operation and integer-bit bounds remain unchanged. No arbitrary code, unbounded
CAS, stochastic/noisy likelihood model or general simulation executor is added.

Sessions have original absolute expiry, at most eight proposal requests, finite
shared setup/lowering/arithmetic work and cumulative native elapsed limits.
Generation has finite calls, output tokens and wall time, and cannot outlive its
native domain. Invalid proposals consume request budget. Every point computation
is counted. Independent verification has its separately bounded fixed Python
process; no NYX shell authority is inferred. Reentry, foreign/cloned references,
revocation, expiry and clock rollback fail closed. A critical independent
derivation disagreement cannot be erased by voting again on the same artifact.

Source parameter literals still have the original 128-digit bound. Derived
measurement scalars can span the original 4096-bit arithmetic range. Both use
the same exact interpreter for normalization: this repairs the source/output
representation mismatch without widening model-parameter admission.

Model artifacts are ephemeral owned data. The CLI does not yet offer this new
generation path; no production deployment or package release is claimed. The
bundled runtime is checked for consistency; unused experimental metadata is
tree-shaken rather than shipped as a cosmetic CLI feature.
Unrelated local UI edits remain outside the milestone.

## Evidence and discovered defects

The scientific suite currently has 92 local checks: independent prediction
replay, rational coefficient variation, immutable data/custody, observational
contradictions, outside-family falsification, ambiguity, scope/cap/deadline
rejection, independent disagreement, reentry and finite NYX repair composition.
Its cognition is explicitly a test double and made zero NVIDIA calls.

Real isolated R3B fixtures demonstrated rational measurement interpretation,
equivalent fraction handling, immutable policy ownership, outside-prediction
outcomes and rejection of executable-looking extra fields, while leaving source
repositories unchanged. These are local E3 execution tests, not instruments or
live cognition. The R3B suite has 55 checks. Independent model-replay detector
validation adds six planted valid/corrupt cases; the prior universal polynomial
detector retains its nine cases and all historical evidence is preserved.

Review found and corrected general boundary defects before publication:
cloning an admitted reference erased process-local ownership; mutable readout
aliases could alter an admitted interpretation; and derived scalars were wrongly
limited by the narrower source literal range. A further measurement-fidelity
gap required coupling numeric results to their planned point/input identity.
Native clocks now pass through the
session's monotonic lifetime guard, and generation stops at the original proposal
cap rather than crashing or silently increasing it. These repairs are not a
claim of cognitive gain.

## Falsifiable next evaluation

### Frozen prospective-model pilot / 1

The next live epoch has three new deterministic scalar-response families:
saturating/control response, coupled quadratic response and nonlinear one-step
response. Each has five admissible calibration points, three registered probes
(one repeated calibration and two prospective points), and five untouched
held-out prediction points. The author simulator coefficients/formula and
held-out inputs never enter cognition. A separately implemented Python Fraction
oracle evaluates the generated original expression only after the arm stops;
the oracle verdict is not repair feedback. Offline detector witnesses are never
supplied as live generation inputs or fallback solutions.

One physical generation prefix produces two or more competing derivation-checked
models. It is charged in full to every arm. This intentionally compares later
workflow choices, not an end-to-end unassisted Nemotron baseline: DIRECT_REVIEW
already receives shared tool-checked generated models; NATIVE_FORECASTS also sees
their exact prospective forecast sheet; NATIVE_EVIDENCE_GUIDANCE adds the owned
graph's assessment and discriminating-experiment recommendation. The latter two
have identical available tools. All arms can request the same typed measurement,
bounded model regeneration, conclusion or no-conclusion action. Unknown tools,
scope/identity errors and malformed data stay inert and are classified separately.

Limits are two shared-generation calls, four action calls and at most one
additional regeneration call per arm; two actual measurements per arm; 8192
output tokens/call; Super hosted-native reasoning/2048 in every call; 240 seconds
per arm including its allocated generation prefix; 180 seconds for generation;
30 minutes total; at most 51 physical logical calls and 51 HTTP attempts.
Regeneration consumes the remainder of the original eight proposal requests,
150000 native work units and 2500 native milliseconds, not a refreshed budget.
All models must fit preserved observations and commit unused-point predictions
before new measurements. Single-use R3B authorities cannot be replayed.

Actual R1/R2A/R3A/R3B fixtures provide pinned, read-only fixed simulator tools in
disposable clones. No generated model source becomes a Node/Python executable.
Each fixture's original source and cleanup are verified. The scalar readback
uses the same admitted observation/root, not a second independent evidence vote.
Setup, actual measurements, generation/native work, replay/grading CPU/wall,
guidance overhead, inference calls/tokens, unknown transport usage and cleanup
are retained separately. Model-internal compute, money, measurement CPU and peak
memory remain unknown rather than zero. Shared allocated cost is not double-
counted as physical cost. A first submitted conclusion is not the first generated
model: first generation admission and first/final submitted acceptance are separate.

Arm order rotates by family. The frozen five-percent realized-inference matching
rule requires equal calls/HTTP attempts and bounded reported-token difference;
equal ceilings alone do not satisfy it. A scoped guidance signal additionally
requires complete independent grading, preserved cleanup, stable/known delivery,
a strict correctness increase, no paired regression and no greater inference.
All outcomes, including no-conclusion and unknown evidence, are preserved.
No three-case result earns cognitive promotion, broad scientific competence,
original discovery or official benchmark success. Fresh family-disjoint transfer,
replication, stronger controls and the full nine-PDF requirements remain pending.

Freeze new scientific model families before inference, separate from these
development calibrations. Require prediction-before-observation and independent
held-out functional acceptance; a function that fits sparse measurements may
still be wrong. Compare a simpler direct/model-only path and same-tool controls
or ablations under the same model, tasks, oracle, authority and finite ceilings.
Charge generation, verification, tool actions, repair, actual tokens/HTTP calls
and unknown usage. Report first and repaired outcomes separately. Do not use
exposed semantic construction tasks, released benchmark answers or an ever-
correct accumulation as scientific generalization.

This component earns a cognitive claim only if fresh outcomes or efficiency
improve under a defensible comparison and replicate. It does not establish
global novelty, causal identifiability, calibrated uncertainty, broad scientific
reasoning or completion of the nine-document program. Physical observation,
domain review and independent replication remain separate prerequisites.
