# Generated scientific model / prospective evidence bridge

Status: experimental component, implemented and locally exercised. Cognitive
advantage, original discovery, physical experimentation and production authority
are not established. The first live comparison has partial coverage and no
comparative promotion; its result is recorded below. Default Ultra is unchanged.

## Actual gap and new capability

The previous science path requires host-supplied `mechanismCatalog` identities,
descriptions and enumerated experiments. NYX can reason about those mechanisms,
commit forecasts and revise after Omega observations, but cannot contribute an
executable mathematical model outside that prewritten catalog. More entities or
more descriptions would not repair that gap.

`runNyxScientificModelGeneration` now uses the existing NYX completion boundary
to propose competing arithmetic models from admitted measurements, input names,
explicit rational parameters, assumptions and uncertainty. Nemotron remains the
shared cognitive substrate: this is not an independently developed reasoning
engine or an additional model controller. Every candidate is data, not a command.

`ScientificModelSession` reuses the exact native workbench and original algebraic
frontend to derive predictions at immutable calibration and prospective inputs.
A separate original-source Python parser/Fraction interpreter checks every point
derivation. A proposed model is rejected if it contradicts admitted exact
measurements; unsupported computation/verifier failures remain insufficient
evidence. Admission means **checked predictions**, not scientific truth.

Only host-owned references can enter the bridge. Generated model identities and
forecasts are registered before constructing the existing immutable research
objective; the original closed-catalog checks are not loosened. The existing
`ResearchEvidenceGraph` commits E1 hypotheses before observations, selects a
discriminating experiment, retains contradictions and concludes only within the
modeled family with independent acceptance false. Correlated models retain one
cognition provenance root, not one independent vote per generated entity.

The existing Omega R3B experiment runner gains an explicit host-owned rational
readout for approved measurement tools. It interprets only a bounded JSON scalar
from the same hash-pinned, separately authorized isolated execution. The
measurement must echo the exact planned point identity and input bindings;
a matching numeric value measured at the wrong input is rejected. Unknown
measurements produce an **outside-all-current-predictions** outcome rather than
manufactured support. Additional fields, malformed output, unauthorized/replayed
execution and unexpected mutations remain rejected. Models cannot supply a
script, command, readout policy or capability token through this interface.

## Scope, resources and ownership

The first domain is deterministic rational scalar response models over 1..3
declared inputs: up to 16 model parameters, 12 admitted measurements and 16
prospective points, using only ADD/SUB/MUL/DIV. Native source-constant, expression,
operation and integer-bit bounds remain unchanged. No arbitrary code, unbounded
CAS, stochastic/noisy likelihood model or general simulation executor is added.

Sessions have original absolute expiry, at most eight proposal requests, finite
shared setup/lowering/arithmetic work and cumulative native elapsed limits.
Generation has finite calls, output tokens and wall time, and cannot outlive its
native domain. Invalid proposals consume request budget. Every point computation
is counted. Independent verification has its separately bounded fixed Python
process; no NYX shell authority is inferred. Reentry, foreign/cloned references,
revocation, expiry and clock rollback fail closed. A critical independent
derivation disagreement cannot be erased by voting again on the same artifact.

Source parameter literals still have the original 128-digit bound. Derived
measurement scalars can span the original 4096-bit arithmetic range. Both use
the same exact interpreter for normalization: this repairs the source/output
representation mismatch without widening model-parameter admission.

Model artifacts are ephemeral owned data. The CLI does not yet offer this new
generation path; no production deployment or package release is claimed. The
bundled runtime is checked for consistency; unused experimental metadata is
tree-shaken rather than shipped as a cosmetic CLI feature.
Unrelated local UI edits remain outside the milestone.

## Bounded coefficient-fitting intervention

The source now contains a process-local, host-enabled coefficient-fitting
capability. `ScientificModelStructure` declares basis expressions and partitions
their output labels into numerator and denominator coefficient identities. NYX
authors that structure; the tool does not select a template, search hidden
equations or receive held-out outputs. Its response form is:

`sum(a_i * phi_i(inputs)) / (original_nonzero_constant + sum(b_j * psi_j(inputs)))`

Calibration cross-multiplication yields an exact linear system. Bounded RREF
uses the **existing** rational interpreter for every scalar operation: at most
12 observation rows, 8 coefficients, original 4096-bit arithmetic limits and
charged parsing/GCD/elimination/original-row residual work. UNIQUE,
UNDERDETERMINED and INCONSISTENT are distinct. Free coefficients are not guessed.
Original source-parameter, expression, definition and operation limits remain;
oversized fitted coefficients and unsupported bases are not silently admitted.

The independent Python verifier reparses the original basis and calibration
with its existing Fraction interpreter, performs elimination/back substitution
and checks rank, coefficients, residuals and generated candidate point semantics.
It does not trust native basis values or pivot claims. A cross-multiplied solution
with zero denominator remains unusable, not a discovered law. Planted coefficient,
rank, candidate-expression and non-unique-completion corruptions test the detector.
Verifier wall/CPU cost is separately observable, not folded into model tokens.

`ScientificModelSession.fit` consumes one original request; ordinary `propose`
consumes another and still independently evaluates the full point population.
Neither renews expiry or work/time limits. Reentry, foreign task identity,
revocation, expired success and a critical independent disagreement fail closed.
High-resolution fitting time is rounded **down** only when transferring the
remaining allowance to the integer-millisecond existing evaluator. This fixes
the fractional-time admission defect found during development without increasing
the budget. Fitting grants no experiment, filesystem, network or production
authority, and cannot itself create an owned model reference.

`runNyxScientificModelGeneration` has an explicit `nativeFit.verify` opt-in.
It composes the same NYX/Nemotron completion boundary, fitting capability and
ordinary proposal verification. Default literal generation and Ultra remain
unchanged. Attempts retain bounded fit states/rank/digests, parser-boundary codes
and usage; they do not persist unnecessary coefficient/source/private reasoning.
The original algebraic diagnostic /1 contract is retained. A separately accessible
finite boundary enum distinguishes the previous generic OTHER's syntax,
trailing-token, function and binding failures; it cannot recover old pilot source.

Development tests exercise rational and multivariable structures, 24 fresh affine
coefficient variations, maximum dense matrices, contradictory/rank-deficient and
zero-denominator cases, corruption detectors, prospective development inputs and
test-double cognition composition. These are E3 component/integration evidence,
**not** new live cognition, broad scientific competence, original discovery or
comparative improvement. No exposed pilot or official benchmark was rerun.
Next freeze family-disjoint live tasks with unchanged independent acceptance,
same-model simpler and same-tool controls/ablations, honest native/verifier/model
compute and first-versus-repaired outcomes. Promotion remains unavailable until
fresh outcomes or efficiency improve under a defensible comparison.

Additional just-in-time coverage: AD10 grounded hypotheses, executable predicted
