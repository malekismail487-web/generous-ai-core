# Engineering standards

These standards apply to all changes in this repository.

1. Make deliberate, scoped changes; do not add rushed or speculative code.
2. Verify each change with the strongest relevant checks that are available, and clearly record any checks that could not be run.
3. Never commit secrets, local environment files, or credential-bearing configuration. Add safe templates instead.
4. Create or update a change dossier in `docs/change-dossiers/` for each completed change set. The dossier must state the scope, exact files changed, verification performed, and remaining limitations.
5. Keep the dossier factual: it must describe only work that was actually completed.
